# 상담 신청 → 구글 시트 실시간 저장 설정

고객 흐름: 랜딩 버튼 클릭 → `/survey` 질문지 → 연락처·동의 → **구글 시트에 즉시 한 줄 저장** → 완료 화면에서 카카오톡 채널 버튼.

## 1. 구글 시트 만들기 (5분)

1. https://sheets.new 에서 새 스프레드시트를 만들고 이름을 정합니다. 예: `상담신청 DB`
2. 메뉴 **확장 프로그램 → Apps Script** 를 엽니다.
3. 기본 코드를 모두 지우고 이 폴더의 `Code.gs` 내용을 붙여넣습니다.
4. 맨 위 두 값을 채웁니다.
   - `SPREADSHEET_ID`: 시트 주소의 `/d/` 와 `/edit` 사이 문자열
   - `SECRET`: 아무도 모르는 긴 문자열 (영문·숫자 30자 이상). 저장소가 공개라 이 값은 GitHub 에 올리지 마세요.
   - 위쪽 함수 선택에서 `setupHeaders` 를 고르고 ▶ 실행 → 시트 1행에 열 제목이 들어갑니다.
5. 저장(💾) 후 오른쪽 위 **배포 → 새 배포**
   - 유형 선택(⚙️): **웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
   - **배포** → 권한 승인(구글 계정 선택 → 고급 → 이동 → 허용)
6. 나오는 **웹 앱 URL** (`https://script.google.com/macros/s/.../exec`)을 복사합니다.

> 웹 앱 URL을 브라우저에서 열었을 때 `{"ok":true,...}` 가 보이면 정상입니다.

## 2. Vercel 에 연결

Vercel → 프로젝트 `jjy` → **Settings → Environment Variables** 에 두 개를 추가하고 다시 배포합니다.

| 이름 | 값 |
| --- | --- |
| `SHEET_WEBHOOK_URL` | 1-6에서 복사한 웹 앱 URL |
| `SHEET_WEBHOOK_SECRET` | 1-4에서 정한 SECRET 값 (똑같이) |

## 3. 시트 1행 (열 순서 고정)

접수시각 · **이름** · **전화번호** · **빌려준금액** · 돈 종류 · 갚기로 한 날 · 보유자료 · 상대방 상황 · 처리상태(기본 "신규") · 담당자 · 메모

- 이름·전화번호·모든 질문 응답·개인정보 동의는 필수입니다. 빠지면 저장되지 않습니다.
- 질문의 열 이름은 `landing.ts` 의 `survey.questions[].column` 입니다. 새 질문을 추가하면 시트 맨 뒤에 열이 자동으로 생깁니다.
- 처리상태·담당자·메모 열은 상담 직원이 직접 쓰는 칸입니다.
- 선택 열: 시트 1행 맨 뒤에 아래 이름으로 열을 직접 추가하면 그때부터 기록됩니다.
  `유입경로` · `캠페인` · `매체` · `키워드` · `광고소재` · `이전페이지` · `첫방문페이지` · `개인정보동의`
  (광고 링크 끝에 `?utm_source=naver&utm_campaign=가을광고` 처럼 붙이면 어느 광고로 들어온 고객인지 남습니다.)

## Apps Script 코드를 고친 경우

**배포 → 배포 관리 → 연필(수정) → 버전: 새 버전 → 배포** 로 다시 배포해야 반영됩니다. (URL은 그대로 유지)
